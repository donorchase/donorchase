Importing and Exporting

If you already keep donor details in a spreadsheet, you can bring them in rather than typing them. Uploading and downloading are for administrators.

Uploads use a CSV file. In Excel, choose File → Save As and pick CSV as the file type.

Upload contacts

Open Settings → Upload Contacts, choose your file and click Upload. The first row must be these headings, in this order:

Donor,Name,Description,Phone,Email

ColumnWhat to enterRequired
DonorThe donor's name, exactly as it appears in DonorChase. Capitals don't matter.Yes
NameThe contact's name.Yes
DescriptionWho they are, such as Mother or Treasurer.No
PhoneTheir phone number.No
EmailTheir email address.No

Use a separate row for each contact when a donor has more than one. Upload only new contacts: a row for a contact the donor already has stops the upload.

Upload comments

Open Settings → Upload Comments, choose your file and click Upload. The first row must be these headings:

Donor,Comment1,Comment2,Comment3,Comment4,Comment5,Comment6,Comment7

You can add up to seven comments per donor. All eight columns must be there, but leave a comment blank if you don't need it. A cell holding just a month label with nothing after it, such as April 26 -, is skipped.

Uploaded comments are dated today and show you as the author, so you may want to put the original date in the text. Each upload adds comments, so uploading the same file twice creates duplicates.

If an upload fails

DonorChase checks the whole file first. If there's a problem, it tells you the line number and nothing is added, so you can fix the file and upload it again.

MessageWhat to do
X columns instead of 5 (or 8)That line has too many or too few columns. Check for missing headings, or a comma in a value that isn't in quotes.
Donor not foundThe name doesn't match any donor. Compare it with the name on your dashboard, including any spaces or initials.
There are multiple donors with the nameTwo donors share this name. Add this one by hand on the donor's page, or make the names different in your bookkeeping package.
There already is a contactThe donor already has a contact with that name. Remove the row from your file.
Lines are duplicatesThe same donor and contact name appear twice in the file. Remove one.
Donor & Name must not be blankFill in both columns on that line.
is an invalid emailCorrect the email address on that line, or leave it blank.

Download a dashboard

Click Download CSV at the bottom of a dashboard to get a spreadsheet of it. It includes every donor on that dashboard, whichever filters are switched on, with their group, balances, last donation, latest comment, team members, chasers and tags.

The period columns match the number set in Terms Shown on Dashboard. To include more periods, raise that number on Settings → Dashboard Setup before downloading.

WhatsApp Messages

Draft your standard messages once, then send them to a donor's contacts in a couple of clicks, with their name and amount filled in. DonorChase prepares the message and opens WhatsApp. You check it and press send there, using your own WhatsApp account.

Draft a message

  1. Open Settings → Messages and click Add Message.
  2. Give it a Name your team will recognise, such as First reminder.
  3. Write the Message. Click a placeholder below the box to add it where your cursor is.
  4. Administrators can tick Shared so that everyone in the organisation can use it. Otherwise only you can see it.
  5. Click Save.

You can edit and delete your own private messages. Only administrators can edit or delete shared ones.

Placeholders

PlaceholderReplaced with
{ContactName}The contact's full name
{ContactFirstName}The contact's first name
{DonorName}The donor's name
{Outstanding}The donor's total amount outstanding. This is the number only, so add your own currency symbol, for example £{Outstanding}.
{LastInvoiceLink}A link for the donor to view their last invoice online (organisations using Xero)
{SchoolName}Your organisation's name

For example:

Hi {ContactFirstName}, this is a friendly reminder from {SchoolName} about the £{Outstanding} pledged by {DonorName}. Thank you for your support.

Send a message

  1. On the donor's page, in the Contacts section, click the WhatsApp button next to the contact's name. It appears only if the contact has a phone number.
  2. Choose the Message. DonorChase fills in the placeholders.
  3. Check the phone number and make any changes to the wording for this donor.
  4. Click Open WhatsApp, then press send in WhatsApp.

Numbers starting with a single 0 are treated as UK numbers. For a number in another country, enter it in international format, starting with + and the country code.

DonorChase doesn't record that a message was sent, so complete a chaser with the method WhatsApp to keep the donor's history up to date.

Wording for voluntary contributions

Some words can make a voluntary contribution sound like a compulsory charge. Unless Invoice Wording is ticked on Settings → Dashboard Setup, DonorChase warns you if a message uses invoice, bill, statement, balance, payment or outstanding.

The warning doesn't stop you. You can save the message anyway, or untick the warning option on that message if the word is deliberate.
